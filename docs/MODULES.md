# 可选模块，按需加入

基础工作台先完成目录、AI 扩展、进度和虚拟示例。下面的东西没有默认安装：

| 模块 | 用处 | 加入前确认 |
|---|---|---|
| 实验记录 | Markdown 记录目的、步骤、结果与下一步 | 使用自己的记录格式，不让 AI 编造数据 |
| 数据制图 | Python/R 读取真实数据出图 | 软件环境、数据来源与统计单位 |
| LaTeX | 编辑和编译 `04_稿件/manuscript.tex` | 可用编译器、下载体积与模板许可；先查已安装环境 |
| 投稿 | 投稿清单、期刊格式、作者信息 | 以期刊最新指南为准，提交由作者确认 |
| 计算模拟 | 项目所需模拟器 | 力场、算力、预算、验收条件另定，不随启动包安装 |

这些是工作区模块的位置与使用建议，不是已自动完成的科研能力。
