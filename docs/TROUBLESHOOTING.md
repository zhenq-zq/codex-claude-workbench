# 卡住了看这里

- **AI 说不能访问电脑**：发给它 MANUAL.md，逐步操作；云端终端不能替你安装本机软件。
- **GitHub 打不开**：换可访问的网络，或让分享者提供原版 ZIP。不要使用未知来源的安装器。
- **账号登录／额度问题**：登录相应官方账号，核对地区、套餐、组织策略。启动包不包含订阅。
- **找不到 code 命令**：Mac 安装版 CLI 常在 `/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code`；脚本也查用户 Applications。Windows 查用户安装目录或 Program Files 下的 bin/code.cmd。
- **Windows 没有 winget**：通过 VS Code 官方下载页手动安装，然后重新运行脚本。
- **Mac 安装评估失败**：停止自动安装，通过官方安装向导处理；不删除隔离属性、不跳过签名检查。
- **脚本被系统策略拦住**：不更改全局执行策略，改用手动步骤或 AI 文件工具。
- **扩展安装失败**：在 VS Code 扩展商店手动安装并核对发布者，不伪造安装成功。
- **看不到 Claude／Codex 面板**：在活动栏打开扩展或命令面板搜索其名称，必要时重载窗口。不要同时覆盖另一窗口的未保存内容。
- **目录已有文件**：脚本跳过同名文件，不覆盖；由 AI 比较模板差异后再决定是否更新。
- **页面刷新没保存**：浏览器本地文件存储可能受限；示例会显示提示。仍可使用基础待办功能。
- **LaTeX 编译失败**：本包未安装 TeX，先读 MODULES.md；不要把目录初始化成功当作论文编译通过。
