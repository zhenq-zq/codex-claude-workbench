# v0.1.0 测试范围

## 已在当前 Mac 做的检查

- shell 脚本语法检查。
- 用独立测试目录完成初始化；再次运行不覆盖用户已改文件。
- 六个编号目录、五份约定/任务/进度文件与 workspace JSON 存在，示例拷贝一致。
- 虚拟网页的勾选计数与刷新保存逻辑以 JS 隔离测试检查；不等于已覆盖所有浏览器。
- 仓库提交前检查绝对私有路径、账号密钥样式和本地缓存未进入发布清单。

## 自动化检查

GitHub Actions 在 macOS、Windows 上运行目录初始化与不覆盖检查；运行状态请看仓库 Actions，未看到绿色结果前不能称 Windows 已通过。

## 尚未证明

- 全新电脑从零下载 VS Code、安装扩展、登录付费账号和完整跨面板交接。
- 不同中国 AI 产品对电脑操作权限与 GitHub 访问能力的支持。
- Linux 脚本部署、所有网络/地区/组织策略、所有浏览器的本地存储。
- LaTeX 编译、真实科研任务质量、发表或科研正确性。

因此当前是**可执行的部署预览版**，不是经过双平台整机验证的一键安装承诺。
